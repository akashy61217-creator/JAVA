# Java Learning Roadmap

A simple topic-by-topic learning order for Core Java. No date-wise schedule.

## 1. Java Basics

- Variables and data types
- Type casting
- Operators and precedence
- User input with Scanner
- if, else-if and nested if
- switch statements
- for, while and do-while loops
- break and continue
- Pattern and number-based programs

## 2. Methods and Problem Solving

- Defining and calling methods
- Parameters and return values
- Method overloading
- Varargs
- Recursion
- Basic problem-solving patterns

## 3. Arrays and Strings

- One-dimensional arrays
- Two-dimensional arrays
- Array traversal, searching and sorting
- Common array coding problems
- String methods and immutability
- StringBuilder and StringBuffer
- String comparison and formatting

## 4. Object-Oriented Programming

- Classes and objects
- Fields and methods
- Constructors and constructor overloading
- Constructor chaining
- this and super
- Encapsulation and data validation
- Inheritance
- Method overriding
- Runtime polymorphism
- Abstraction and abstract classes
- Interfaces and multiple-interface implementation
- Type casting and instanceof
- static and final
- Access modifiers and packages
- Object class methods: toString(), equals(), hashCode()
- Immutable classes

## 5. Core Language Features

- Wrapper classes
- Autoboxing and unboxing
- Enums
- Static nested and inner classes
- Local and anonymous classes
- Generics: classes, methods, bounds and wildcards

## 6. Collections Framework

- List: ArrayList and LinkedList
- Set: HashSet, LinkedHashSet and TreeSet
- Map: HashMap, LinkedHashMap and TreeMap
- Queue and Deque
- Iterator and ListIterator
- Comparable and Comparator
- Sorting and searching collections

## 7. Exception Handling

- try, catch and finally
- Checked and unchecked exceptions
- throw and throws
- Custom exceptions
- Exception propagation
- try-with-resources

## 8. File Handling and Useful APIs

- Byte streams and character streams
- BufferedReader and BufferedWriter
- FileInputStream and FileOutputStream
- Path and Files (NIO)
- File and directory operations
- Regular expressions
- Date and Time API

## 9. Functional Programming and Modern Java

- Functional interfaces
- Lambda expressions
- Method references
- Stream API
- filter, map, reduce and collect
- Collectors and grouping
- Optional
- Records
- Sealed classes
- Switch expressions
- Text blocks
- Annotations and basic reflection

## 10. JVM and Multithreading

- JVM, JRE and JDK
- Class loading
- Stack and heap memory
- Garbage collection basics
- Thread and Runnable
- Callable and Future
- Race conditions
- synchronized and locks
- volatile
- ExecutorService
- CompletableFuture

## 11. JDBC and SQL Connectivity

- Database connection with JDBC
- DriverManager and Connection
- Statement and PreparedStatement
- ResultSet
- Insert, select, update and delete (CRUD)
- Transactions and commit/rollback
- Batch operations
- Java program connected to a SQL database

## 12. Practical Coding Projects

- Console-based Student Management System
- Bank Management System
- File-based record management
- JDBC-based CRUD application
- Final integrated console project using OOP, collections, exceptions, file handling and JDBC

## Daily Practice Routine

- 15 minutes: revise and re-solve an old problem
- 85 minutes: write programs for the current topic
- 20 minutes: test edge cases, debug and note mistakes

## How to Mark a Topic Complete

- Code compiles and runs.
- Solve at least 5 problems without copying.
- Test normal and edge-case inputs.
- Explain the solution in your own words.
- Save your solutions under `practice/<topic>/`.
