# Java Learning Repository

Core Java practice files are stored in `learnings/Java_all_lec/`. The folder matches the package path already used by several source files. The sequence below is the recommended order for studying them.

## Study order

1. **Java basics** — `Variables.java`, `Lec_no_12.java` (operators and precedence), `Conditional_statement.java`, `Switch_statement18.java`, `Switch_case_breakProgram.java`
2. **Input and simple programs** — `Details.java`, `Main.java`, `Test_age.java`
3. **Loops** — `WhileLoop_lec21.java`, `For_loopUsing_lec_no23.java`, `LecNo_24_BreakAndContinue_UsingLoop.java`, `Table.java`
4. **Strings** — `Lec_no_13IntroductionString.java`, `SetNo_p3.java`
5. **Arrays** — `ArrayExample.java`, `Arrays_lecNo_26.java`, `Lec_No_27.java`, `Chap_No_06.java`, `CalculateSumOfAllElements.java`, `FindLargestNumber.java`, `Chap_04PracticeSet.java`
6. **OOP fundamentals** — `CBSCstudent.java`, `Vehicle.java`, `Bike.java`, `Mobile.java`, `Motorola.java`, `Cal.java`, `CalClient.java`, `Client.java`
7. **Abstraction and interfaces** — `Abstract_Method.java`, `Interface_Concept.java`, `Interface_in_Inheritance.java`
8. **Exception handling** — `Array_Exception.java`, `FirstTest_Exception.java`, `ProblemSloveException.java`, `String_Exception_Problem.java`, `ThrowInExceptionHandling.java`, `TryOrCatchExample.java`
9. **Practice / revision** — `Game_stone_paper_scissor.java`, `lec_No_17.java`, `client2.java`

## Notes

- These are standalone learning exercises, not yet a single Maven/Gradle application.
- Some examples contain incomplete code or logic bugs; organize first, then fix and test them one by one.
- `client2.java` currently imports `learnings.Student`; that class is not present in this repository, so this example will not compile until the missing class is added.
- Start with the first section and move forward only after you can explain and modify each example yourself.

## Goal

Build a strong Core Java foundation before moving to JDBC, SQL, Spring Boot, and backend projects.
