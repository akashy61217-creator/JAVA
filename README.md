# Java Learning Repository

Core Java practice repository arranged in learning order.

## Folder structure

- `learnings/Java_all_lec/` — existing lecture examples and practice programs
- `JAVA_ROADMAP.md` — remaining Core Java concepts, daily coding checklist from 21 November to 31 December 2026, and the 9 PM–11 PM routine
- `practice/<topic>/` — add new independent solutions here as you work through the roadmap

## Recommended learning order

1. Java basics: variables, operators, conditions and loops
2. Input/output and console programs
3. Strings and arrays
4. Methods and problem-solving
5. Classes, constructors and OOP
6. Abstraction, interfaces and packages
7. Exceptions
8. Generics and Collections
9. File I/O and useful Java APIs
10. Lambdas, Streams and Optional
11. Multithreading and concurrency
12. JDBC and a console project

**Daily target:** 9:00 PM–11:00 PM. Write and test code every day; do not count passive video watching as practice.

See [JAVA_ROADMAP.md](JAVA_ROADMAP.md) for the full day-wise plan and completion checklist.
